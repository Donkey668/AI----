# UI Parity Contract

基准：锁定提交 app/_components、app/globals.css、components/ui。

- 保持 analysis/identify/records 三屏、默认分析、280ms 转场、连续切换和 reduced-motion。
- 保持 430px 窄屏、桌面“移动端体验最佳”提示和小屏粗指针横屏限制；不重设计 PC 分栏。
- 分析页保持默认公园、地图选择同步、天气/指数/概览、鸟种视图、预报预警弹窗。
- 识别保持上传/预览/提交及无鸟、失败、百科局部失败的卡片状态。
- 登录保持原校验、弹窗关闭限制、刷新会话、退出、注册提示；不补自助注册。
- 记录保持未认证提醒、新增/编辑/删除、手填/设备/地图定位、摘要/空态/错误态及 TXT 导出。
- 图片适配保持尺寸/比例/加载和预览；字体保留 Geist/Geist Mono，通过同尺寸截图对照。
- 地图和模型动态内容不要求逐像素相同，但字段、布局、交互和状态必须一致。
- 浏览器不得引入账号库、Map、fs、node:crypto、服务端密钥；共享类型/常量与服务实现隔离。
